# Support

## Community support

- Use GitHub Discussions for design and usage questions once enabled.
- Use GitHub Issues for reproducible bugs and scoped feature proposals.
- Use private vulnerability reporting for security issues.

Community support for the public product is best-effort. The complete
Apache-2.0 product can be self-hosted without a commercial entitlement, license
server, billing endpoint, or mandatory call-home.

## Operated service and commercial support

A separately maintained proprietary sibling owns the operated service,
billing and service plans, multi-deployment fleet operations, managed-client
operations, and commercial support grants and entitlements. Response times,
SLAs, LTS commitments, training, migration, and incident-response obligations
exist only when stated in a separate service agreement.

Buying a hosted-service or support entitlement does not unlock, relicense, or
complete the public product. All source already published under Apache-2.0
keeps that historical grant. See [`OPEN_CORE.md`](./OPEN_CORE.md) for the full
boundary and [`SECURITY.md`](./SECURITY.md) for reporting channels.
