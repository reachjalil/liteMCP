# Shared agent resources

This directory is the reviewed source for portable LiteMCP skills projected to
both `.agents` and `.claude`. The generated target folders are disposable;
change skills here and regenerate them with the root Harness scripts.

`skills/harness-config` is the reviewed upstream migration and maintenance
guide recorded in `skills-lock.json`. The `litemcp-*` skills encode focused
repository workflows and link back to authoritative project documentation
instead of duplicating product policy.
